# c-manager v1.4.8

This release adds a low-profile way to correct **actual** workflow dates without adding more permanent fields to the interface.

In **Completed**, open the small **⋯** menu on a Result and choose **Adjust actual dates**.

You can correct:

- **Actually completed at**
- **Actually published at**

This is intended for cases where a user completed or published work earlier but forgot to press the corresponding action on that day.

Planned dates stay unchanged, while Calendar history moves to the corrected actual dates.
