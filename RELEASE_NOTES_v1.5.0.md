# c-manager v1.5.0

v1.5.0 introduces a dedicated **Statistics** workspace.

The new dashboard turns c-manager history into a visual analytics layer rather than only a planning interface.

## Dashboard

Top-level metrics include:

- Tracked Results
- Completed
- Published
- Ready to publish
- In progress
- Average score

## Charts

- **14-day activity** — grouped daily bars for actual Completed and Published activity.
- **Pipeline status** — donut chart for In progress, Ready to publish and Published.
- **Concept categories** — usage distribution using the user's category colours.
- **Music categories** — usage distribution using the user's category colours.

## Rankings and insights

- Most-used Ideas
- Most-used Concepts
- Most-used Music
- Top Results by score
- Most productive day
- Top Concept category
- Top Music category

## Planning performance

Statistics also compare planned dates with actual dates for:

- Execution on time
- Publication on time
- Average number of days early or late

Actual-date corrections introduced in v1.4.8 automatically flow into the Statistics dashboard.

Everything is rendered locally with native HTML/CSS/JavaScript and no third-party chart library.
