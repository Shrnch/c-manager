# c-manager v1.5.2

Workspace source items can now be completed instead of only edited or deleted.

Each **Idea**, **Concept** and **Music** cell has a small **✓** action.

When used:

- the item moves out of Workspace;
- it appears in **Completed**;
- it is not deleted;
- existing Results that use it remain intact;
- it can be restored later with **Restore to workspace**.

If the item was currently selected for a new Result, that selection is cleared automatically.
