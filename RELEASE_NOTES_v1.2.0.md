# c-manager v1.2.0

Random can now build a combination around one or two manually chosen source items.

## Partial Random

Selected cells are treated as locked:

- select nothing → Random chooses Idea + Concept + Music;
- select one cell → Random fills the other two;
- select two cells → Random fills only the remaining one;
- select all three → Random changes nothing and asks you to deselect the slot you want randomized.

## Category filters

Concept and Music category filters still constrain Random. If an unselected column is filtered to a category, Random chooses only from the visible items in that category.
