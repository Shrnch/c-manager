# c-manager v1.4.5

This patch makes the **Day Overview** event-type filter easier to scan.

Each filter option now uses the same color as its matching Calendar event:

- Execution planned — orange;
- Execution plan completed — orange;
- Completed — green;
- Publication planned — purple;
- Publication planned — still in progress — lighter purple;
- Ready to publish — stronger purple;
- Published — teal.

The selected filter value is also shown in its matching color when the dropdown is closed.
