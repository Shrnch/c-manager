# c-manager v1.5.1

The Statistics **Activity** chart is now easier to read and can cover different time ranges.

## Axes

The chart now includes numeric Y-axis values and an explicit zero baseline, so every bar has a clear meaning and starts from the graph axis.

## Period selector

Available ranges:

- 7 days
- 14 days
- 30 days
- 3 months
- 6 months
- 1 year
- All time

Longer ranges are automatically grouped into weeks, months or years to keep the visualization readable.

**All time** adapts the grouping to the actual span of the user's history.

The X axis also reduces label density automatically when a period contains many buckets.
