# c-manager v1.2.1

This patch fixes repeated use of Partial Random.

## Fixed behavior

Manual choices are now treated as locks, while values generated by Random remain unlocked.

Examples:

- select an Idea manually → every press of Random keeps that Idea and rerolls Concept + Music;
- select Idea + Music manually → every press rerolls only Concept;
- select nothing manually → every press rerolls all three;
- select all three manually → Random changes nothing.

When a column contains multiple eligible items, Random also tries to avoid returning the same item on the next press.
