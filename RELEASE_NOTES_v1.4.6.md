# c-manager v1.4.6

Completed Results can now be rescheduled for publication without being restored to Workspace.

For an unpublished Result in **Completed**:

- edit **Publication planned** directly;
- the original completion date stays untouched;
- the Result remains Completed;
- Calendar updates immediately;
- **Mark as published** remains available.

The publication plan can also be cleared if no publication date is currently known.
