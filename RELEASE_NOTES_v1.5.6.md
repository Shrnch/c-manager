# c-manager v1.5.6

Result source links are no longer limited to Workspace.

Completed and Archive Result cards now show the same expandable Links panel used by Workspace whenever the linked Idea, Concept or Music item has a URL.

Calendar Day Overview cards also show that Links panel, so a source link can be opened directly from the calendar without restoring or moving the Result.

This update does not modify stored data or change the localStorage schema.
