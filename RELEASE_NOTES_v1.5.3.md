# c-manager v1.5.3

Music no longer requires an Artist.

When adding or editing Music:

- **Track title** is required;
- **Artist** is optional.

If Artist is present, the Music cell keeps the existing two-level layout:

**Artist**  
Track title

If Artist is omitted, c-manager displays only the Track title as the main label.

The same clean formatting is used throughout Results, Calendar, Statistics, Completed/Archive views and workflow dialogs, so title-only tracks never appear as `— Track title`.
