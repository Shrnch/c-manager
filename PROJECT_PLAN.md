# PROJECT_PLAN — Content Idea Organizer

## 1. Цель проекта

Сделать локальное веб-приложение для создания контент-идей из трёх компонентов:

1. **Идея** — формат видео или поста.
2. **Концепт** — тема контента.
3. **Музыка** — композиция для видео или поста.

Пользователь выбирает по одному элементу из каждого столбца, получает комбинацию, сохраняет её как **результат**, назначает дату и время, а затем оценивает по важности и желанию.

Основной визуальный ориентир — таблица из трёх столбцов с видимыми линиями между связанными ячейками.

---

## 2. Что входит в первую рабочую версию

### Обязательно

- три столбца: **Идеи**, **Концепты**, **Музыка**;
- добавление, редактирование и удаление элементов;
- категории концептов;
- выбор одной ячейки в каждом столбце;
- создание результата из трёх выбранных ячеек;
- видимые линии между связанными ячейками;
- возможность использовать одну ячейку в нескольких результатах;
- отдельный список сохранённых результатов;
- дата и время результата;
- удаление результата;
- ползунок **Важность** от 0 до 10;
- ползунок **Желание** от 0 до 10;
- итоговый балл;
- сортировка результатов;
- кнопка **Random**;
- автоматическое сохранение данных на компьютере пользователя.

### Пока не входит

- регистрация и аккаунты;
- сервер и база данных;
- синхронизация между устройствами;
- совместная работа;
- мобильное приложение;
- публикация контента в социальные сети;
- подключение Spotify, YouTube или Instagram API;
- искусственный интеллект.

## 3. Принятые решения для MVP

### Технологии

Используем обычное локальное веб-приложение:

- HTML;
- CSS;
- JavaScript;
- SVG для линий;
- `localStorage` для сохранения данных.

Для запуска достаточно открыть `index.html` в браузере. Если браузер ограничит работу модулей, запускаем проект через локальный сервер VS Code Live Server.

### Создание комбинации

В первой версии пользователь:

1. нажимает на одну идею;
2. нажимает на один концепт;
3. нажимает на одну композицию;
4. нажимает **Создать результат**.

После этого:

- создаётся сохранённый результат;
- между тремя ячейками появляются линии;
- результат появляется в отдельном списке.

Перетаскивание проводов мышкой можно добавить после завершения MVP.

### Формула оценки

Диапазоны:

- важность: `0–10`;
- желание: `0–10`.

Формула первой версии:

```text
Итоговый балл = Важность × 2 + Желание
```

Таким образом, важность влияет на итог сильнее желания.

### Сортировка

Результаты можно сортировать:

- по итоговому баллу;
- по важности;
- по желанию;
- по дате создания;
- по назначенной дате.

- `styles.css` — внешний вид;

- `js/state.js` — данные приложения и операции с ними;
- `js/storage.js` — сохранение и загрузка из `localStorage`;
- `js/render.js` — отображение столбцов и результатов;
- `js/connections.js` — расчёт и отрисовка линий;
- `PROJECT_PLAN.md` — постоянный план разработки;
- `PROJECT_STATE.md` — текущее состояние проекта;
- `README.md` — инструкция по запуску.

Над тремя столбцами располагается прозрачный SVG-слой.

Для каждого сохранённого результата рисуются:

1. линия от идеи к концепту;
2. линия от концепта к музыке.

### Сделать

- [ ] определить координаты центров нужных ячеек;
- [ ] рисовать плавные SVG-кривые;
- [ ] присвоить каждой ячейке HTML-атрибут с её ID;
- [ ] перерисовывать линии после добавления результата;
- [ ] перерисовывать линии после удаления результата;
- [ ] перерисовывать линии при прокрутке;

- [ ] использовать разные стили линий, чтобы пересечения оставались читаемыми.

### Важно

Одна ячейка может иметь несколько исходящих линий. Линии принадлежат результатам, а не уничтожают и не блокируют другие связи.
