# Content Idea Organizer v0.1.0

Первый рабочий MVP приложения для организации контент-идей.

## Главное

Пользователь соединяет идею, концепт и музыку, сохраняет результат, назначает дату и оценивает его по важности и желанию.

## Что уже работает

- управление всеми тремя типами элементов;
- категории концептов;
- Random;
- несколько результатов;
- видимые провода;
- оценки и сортировка;
- фильтры;
- локальное сохранение;
- JSON-резервные копии.

## Запуск

Откройте `index.html` или используйте VS Code Live Server.

## Ограничения

Облачное хранение, аккаунты, совместная работа и перетаскивание проводов не входят в `v0.1.0`.
